# Valentine Web App

## Overview
A playful Valentine's Day web application that asks "Ashmeen, will you be my Valentine?" with interactive buttons for a fun user experience.

## Core Features

### Main Interface
- Display centered message: "Ashmeen, will you be my Valentine?"
- Show two buttons: "Yes" and "No"
- Pink romantic background with heart decorations
- Soft transitions and playful typography
- Responsive design for mobile and desktop

### Interactive Behavior
- **"No" Button**: When clicked, the button moves to a random position on screen and cycles through playful rejection phrases:
  - "Are you sure?"
  - "Really?"
  - "Try again!"
  - "No escape!"
  - "You can't escape love!"
- **"Yes" Button**: When clicked, hide the question and display:
  - A romantic picture showing the shadow of a kissing couple
  - Below the picture, display the message: "You've made me the happiest! 💖 This Valentine's Day is going to be magical with you by my side... Can't wait to celebrate with you, Meri Ash."
  - Animate the text with a soft fade-in and heart shimmer effect for a magical feel

### Styling Requirements
- Pink color scheme with romantic aesthetics
- Heart decorations and visual elements that continue floating gently in the background
- Smooth animations and transitions
- Centered layout with proper spacing
- Mobile-responsive design
- Playful, romantic font styling
- Heart shimmer effect for the romantic message text

## Technical Requirements
- Frontend-only application (no backend data storage needed)
- All interactions handled in the frontend
- Smooth animations using CSS transitions
- Random positioning logic for the moving "No" button
- Fade effects and heart shimmer animations for the romantic message
- App content language: English
